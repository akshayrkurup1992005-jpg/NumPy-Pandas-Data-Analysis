## 📌 Project Overview

This project is a practical introduction to **Python-based Data Analysis** using two powerful libraries: NumPy and Pandas.

The main focus is to understand how data can be created, accessed, explored, transformed, and analyzed through hands-on programming exercises.

The project covers numerical analysis using temperature datasets, student marks management using Pandas Series, and transaction data exploration using Pandas DataFrames.

It demonstrates the fundamental techniques required to build a strong foundation in Data Analytics.

## 🎯 Project Objectives

- Understand numerical computing using NumPy.
- Create and manipulate one-dimensional and two-dimensional arrays.
- Perform mathematical and statistical operations.
- Work with Pandas Series and DataFrames.
- Apply indexing, slicing, and conditional filtering.
- Explore structured datasets and identify patterns.
- Perform grouping, aggregation, and data transformation.

## 📚 Project Breakdown

### 01 | NumPy – Numerical Computing

Exploring numerical data through temperature-based datasets.

**Key Concepts:**
- Creating 1D and 2D arrays
- Understanding array dimensions, shape, size and data types
- Mathematical operations on arrays
- Celsius to Fahrenheit conversion
- Maximum, minimum and mean calculations
- Array indexing and slicing
- Extracting weekly and weekend temperature records

### 02 | Pandas – Series Manipulation

Working with student marks using labeled one-dimensional data structures.

**Key Concepts:**
- Creating Series with custom indices
- Integer and label-based indexing
- Using `loc` and `iloc`
- Boolean masking and data filtering
- Updating and removing elements
- Performing calculations on Series
- CGPA calculation

### 03 | Pandas – DataFrame Analysis

Analyzing structured transaction records using DataFrames.

**Key Concepts:**
- Creating DataFrames
- Exploring datasets using `head()`, `tail()` and `info()`
- Understanding dataset shape and data types
- Selecting specific columns
- Conditional filtering using `query()`
- Identifying unique values
- Category-wise frequency analysis
- Grouping data using `groupby()`
- Calculating regional average transaction amounts
- Adding, updating and deleting columns and rows

## ⚙️ Getting Started

Follow these steps to run the notebook locally.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/NumPy-Pandas-Data-Analysis.git
```

**2. Navigate to the project directory**

```bash
cd NumPy-Pandas-Data-Analysis
```

**3. Install the required libraries**

```bash
pip install numpy pandas jupyter
```

**4. Start Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open the notebook**

Open `NumPy&Pandas.ipynb` and execute the cells sequentially.
